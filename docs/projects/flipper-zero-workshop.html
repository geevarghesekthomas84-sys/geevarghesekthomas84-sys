Flipper Zero Workshop

Take a Flipper Zero apart in 3D and learn how it works

Open live demo ↗View on GitHub ↗

A free, browser-based Flipper Zero simulator. Explore the device in 3D, take it apart, and learn how it works through hands-on lessons. This is an unofficial educational project, shared as a showcase without source code.

What it does

  • Interactive 3D model you can take apart
  • 50 interactive lessons
  • Runs in the browser with nothing to install
  • Unofficial educational project
