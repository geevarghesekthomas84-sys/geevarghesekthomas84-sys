RedPilot

AI-orchestrated offensive security framework

View on GitHub ↗PyPI ↗

Point RedPilot at a target and it runs the engagement. The AI plans the recon, RedPilot runs the tools on your own machine, and you get findings plus a written assessment. Authorized testing only.

What it does

  • Staged pipeline: discovery, validation, remediation, then report
  • Automated reconnaissance and CVE mapping
  • Exploit proof-of-concept generation and remediation guidance
  • Drivable from the CLI, an HTTP API, MCP, or a dashboard
  • Works with Gemini, Claude, Ollama and LM Studio models
