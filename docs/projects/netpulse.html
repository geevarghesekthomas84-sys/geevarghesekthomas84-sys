NetPulse

Interactive network simulator in your browser

Open live demo ↗View on GitHub ↗

An interactive internet protocol visualizer and Packet Tracer-style network simulator that runs entirely in the browser, so you can learn how networks behave without installing anything.

What it does

  • 39 protocols visualized interactively
  • IOS-style command-line interface
  • DHCP, VLANs, and OSPF, RIP and BGP routing
  • 20 guided labs
  • Available in 6 languages
