Gria-AI

Private on-device Android AI assistant

View on GitHub ↗

A premium ChatGPT-style Android chat app that keeps conversations private by running models locally instead of sending them to a cloud service.

What it does

  • Local LLM inference, including on-device Gemma at around 40 tokens per second
  • Quiet Luxury UI with SSE streaming responses
  • Voice speech-to-text input
  • Biometric vault and live hardware telemetry
  • Syntax highlighting and switchable personas
