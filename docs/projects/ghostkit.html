GhostKit

Portable offensive security suite for USB

View on GitHub ↗

A drop-and-run toolkit for field operations that carries its own tooling and an offline AI assistant on a USB drive.

What it does

  • AI-assisted network auditing with Nmap
  • Web vulnerability scanning with Nuclei
  • Packet analysis with Wireshark
  • Offline AI security assistant powered by local LLMs
  • Runs from a USB drive
