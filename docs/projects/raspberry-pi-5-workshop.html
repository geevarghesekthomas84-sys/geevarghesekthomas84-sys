Raspberry Pi 5 Workshop

Wire real parts to a 3D Raspberry Pi 5 and run real Python

Open live demo ↗View on GitHub ↗

A free, browser-based Raspberry Pi 5 simulator. Wire real components to a 3D Pi 5, write and run real Python, and work through hands-on projects. This is an unofficial educational project, shared as a showcase without source code.

What it does

  • 3D Raspberry Pi 5 you can wire real parts to
  • Runs real Python using gpiozero
  • 9 projects to build
  • 50 interactive lessons
